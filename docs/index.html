What it actually does

Four things a general chatbot in a browser tab can't.

🎯

Knows your place

Once the Studio plugin is connected, it sees your place name, your Explorer selection and which scripts already exist — so it targets real containers instead of inventing them.

⚡

Send to Studio

Every complete script is tagged with where it belongs. One click inserts it — updating an existing script of the same name rather than making a duplicate, and always as a single Ctrl+Z.

🏗️

Build mode

Flip one toggle and it builds inside your open place itself: creates parts, folders, GUIs and scripts, reads the place back to check its work, and shows every action live as it happens.

📚

A Luau specialist

Modern Luau, the client/server boundary, remotes with validated arguments, DataStores, replication. It writes whole files, never fragments — a half script is a broken script.

What you need first

Two of these you almost certainly already have. The third is the one to read carefully.

✓
Windows 10 or 11, 64-bit.

RoForge installs per-user, so it never asks for admin rights. No macOS or Linux build.

✓
Roblox Studio.

Optional, strictly speaking — you can use RoForge as a Roblox-flavoured chat window on its own — but the whole point is the connection.

✓
A model to think with.

RoForge doesn't come with an account; it uses yours. Any of the three below works — including one that costs nothing and needs no account anywhere.

If you have Claude

Your Claude subscription

RoForge drives the Claude Code CLI already on your PC, so there are no per-token charges — it's covered by Claude Pro or Max. Install the CLI once: 

npm install -g @anthropic-ai/claude-code
claude   # sign in with your Claude account

Needs Node.js. This is the default — nothing to configure in RoForge.

No account needed

A model on your own PC

Install Ollama, pull a coding model, and point RoForge at it. Free forever, works with the Wi-Fi off, and nothing about your game leaves the machine. 

ollama pull qwen2.5-coder:14b

In Settings: Runs on → Any other model, provider Ollama, then Load and pick it. No key, no card, no sign-up.

Free tiers & pay-as-you-go

A hosted model

The same setting takes a key from OpenRouter, Groq or Google AI Studio — all with genuine free tiers — or an Anthropic key if you'd rather have Claude on pay-as-you-go credits.

Note: a Claude Pro/Max subscription does not fund an Anthropic API key — that's a separate balance you top up. “Credit balance is too low” means this, and switching model won't help.

Every key is encrypted with Windows DPAPI and only ever sent to the provider you chose. One caveat worth knowing before you pick: build mode asks the model to plan and run a long series of actions. Claude and the bigger hosted models handle that; a small local model will usually write a script or two and then lose the thread. Ordinary chat and Send to Studio are fine on anything.

Install it

About two minutes, most of it Studio restarting.

  1. Download and run the installer.

    It's a one-click per-user install: RoForge lands in %LOCALAPPDATA%\Programs\RoForge with a desktop and Start Menu shortcut, plus an entry in Add or Remove Programs. It launches itself when it's done.

    Windows will warn you. The installer isn't code-signed — signing certificates cost hundreds a year — so SmartScreen shows “Windows protected your PC”. Click More info → Run anyway. If you'd rather not trust a stranger's binary, the full source is public — every line of it is there to read.
  2. Pick what it runs on.

    Open Settings (the gear in the title bar). Runs on defaults to Your Claude subscription — if you installed the Claude Code CLI above, there's nothing to do here.

    No Claude account? Choose Any other model, pick a provider, press Load to see what it offers, choose one, then Test this model to confirm it answers. With Ollama that's the whole setup — no key, nothing to pay.

  3. Say hello.

    Type a question and you're working. Press Ctrl+Alt+R anywhere in Windows to show or hide the window — it opens down the right-hand side of the screen, sized to sit beside Studio rather than on top of it.

Connect Roblox Studio

This is what turns it from a chat window into something that can build.

  1. Settings → Install plugin into Roblox Studio.

    That copies the plugin into %LOCALAPPDATA%\Roblox\Plugins for you. Nothing to download separately, nothing to drag anywhere.

  2. Restart Studio, then click the RoForge button on the Plugins tab.

    Studio only picks up new plugins on start-up. Once you click the button the chip in RoForge's title bar turns green and shows your place name.

  3. Allow script injection when Studio asks.

    This is required — without it the plugin can create a script but can't write anything into it. If the plugin reports it can't reach the app, also enable Allow HTTP Requests under Game Settings → Security.

  4. Ask for something and press Send to Studio.

    Or flip the Build in Studio toggle next to the composer and just describe the game — it'll create the parts, folders and scripts itself, in dependency order, and tell you what it made when it's done.

    Every insert and every build action is a single Ctrl+Z in Studio. Nothing is unrecoverable.

How the connection works

Nothing can dial into Studio from outside, so the plugin polls instead: every 3 seconds it posts a small snapshot of your place to 127.0.0.1:8095 and collects any pending work. That server is bound to loopback only — it accepts instructions to write scripts into your game, so it has no business being reachable from the network. Nothing about your place is sent anywhere except to Anthropic as part of the conversation you're having.

When something's off

The handful of things that actually go wrong.

Windows says “Windows protected your PC” and won't run the installer

Expected — the build isn't code-signed. Click More info, then Run anyway. If your antivirus quarantines it instead, that's the same unsigned-binary heuristic; you may need to allow it explicitly.

The chip says “Studio open · not linked”

Studio is running but the plugin hasn't checked in. Click the RoForge button on the Plugins tab. If it isn't there, run Settings → Install plugin into Roblox Studio again and restart Studio — Studio only loads plugins at start-up.

It says the plugin is out of date

The app and plugin check each other's protocol version, and RoForge would rather tell you than half-build against an old plugin. Re-run the install button in Settings, then restart Studio. Studio sometimes takes a minute or two to notice a plugin file changed, which is why a restart is the reliable fix.

Build mode refuses to start

It needs Studio connected and on a current plugin. Check the chip is green first. Ordinary chat works regardless — turn the toggle off and insert code yourself with Send to Studio.

“Your credit balance is too low”

You're on the Anthropic API-key engine with an empty balance. Either top up at console.anthropic.com, or switch Runs on to Your Claude subscription — or to Any other model and use a free provider. Choosing a cheaper model does not avoid API billing: any model on an API key is billed.

“Nothing is answering on http://127.0.0.1:11434/v1”

That's the local-model option with Ollama not running. Open the Ollama app (or run ollama serve), make sure you've pulled at least one model with ollama pull qwen2.5-coder:14b, then press Load in Settings again.

The model list is empty, or my model isn't in it

RoForge lists what the server itself reports. For Ollama that's what you've pulled; for a hosted provider it's what your key can reach. If the list is empty the address is probably wrong — it must include the version path, e.g. http://127.0.0.1:11434/v1, not just the host.

A local model keeps losing track during a build

Expected, and not something a prompt fixes. Build mode is a long chain of tool calls, which small models handle poorly. Use a bigger model for building — a free hosted one is fine — and keep the local model for questions and Send to Studio.

A script went somewhere I didn't expect

It won't invent containers — only real ones (ServerScriptService, ReplicatedStorage, StarterPlayer, …) are accepted, and missing folders in between get created. Select something in the Explorer and ask for it “in my selection” to pin it exactly. And Ctrl+Z undoes any insert in one press.

Where's my chat history and API key stored?

%APPDATA%\RoForge. It survives reinstalls and upgrades, and the key is encrypted with Windows DPAPI so it's only readable by your Windows account. Uninstalling leaves the folder alone — delete it by hand if you want it gone.
